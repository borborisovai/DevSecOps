## Найденные дефекты

Для каждого самостоятельного дефекта:
### Дефект 1. Скидка 5% не применяется при сумме ровно 5000
- **Нарушенное требование:** R2
- **Входные данные:** `subtotal = 5000m`, `loyalty = false`, `express = false`
- **Ожидаемый результат и расчёт:**  
  5000 ≥ 5000 → скидка 5% → 5000 × 0.95 = 4750.  
  Обычная доставка бесплатна, так как 5000 ≥ 4000.  
  Итог: **4750**.
- **Фактический результат:** `5000`
- **Имя теста:** `RegularOrder_5000WithoutLoyalty_TotalIs4750`

### Дефект 2. Скидки складываются вместо выбора большей
- **Нарушенное требование:** R3 (дополнительно R5)
- **Входные данные:** `subtotal = 5000.01m`, `loyalty = true`, `express = true`
- **Ожидаемый результат и расчёт:**  
  Подходят скидки 5% (сумма ≥ 5000) и 10% (карта).  
  По R3 применяется только большая — 10%.  
  5000.01 × 0.9 = 4500.009 → округление `AwayFromZero` до двух знаков → 4500.01.  
  Затем прибавляется экспресс-доставка 500.  
  Итог: 4500.01 + 500 = **5000.01**.
- **Фактический результат:** `4250.01`  
  Соответствует применению 15% скидки: 5000.01 × 0.85 = 4250.0085 → 4250.01.  
  Экспресс-доставка также не добавлена.
- **Имя теста:** `ExpressOrder_5000_01WithLoyalty_TotalIs5000_01`

### Дефект 3. Экспресс-доставка не добавляется при сумме от 4000
- **Нарушенное требование:** R5
- **Входные данные:**  
  `subtotal = 4000m`, `loyalty = false`, `express = true`  
  и `subtotal = 4000m`, `loyalty = true`, `express = true`
- **Ожидаемый результат и расчёт:**  
  Для 4000 без карты: обычная доставка была бы бесплатной, но экспресс заменяет её и стоит 500.  
  Итог: 4000 + 500 = **4500**.  
  Для 4000 с картой: скидка 10% → 4000 × 0.9 = 3600.  
  Затем экспресс 500 → **4100**.
- **Фактический результат:**  
  `4000` (экспресс не добавлен)  
  `3600.00` (экспресс не добавлен)
- **Имена тестов:**  
  `ExpressOrder_4000WithoutLoyalty_TotalIs4500`  
  `ExpressOrder_4000WithLoyalty_TotalIs4100`

### Дефект 4. Неверный итог при сумме 3999.99 без карты и с обычной доставкой
- **Нарушенное требование:** R2 / R4 (требуется уточнение)
- **Входные данные:** `subtotal = 3999.99m`, `loyalty = false`, `express = false`
- **Ожидаемый результат и расчёт:**  
  3999.99 < 5000 → скидки по сумме нет.  
  3999.99 < 4000 → обычная доставка стоит 300.  
  Итог: 3999.99 + 300 = **4299.99**.
- **Фактический результат:** `4099.99`  
  Это значение может быть получено двумя способами:  
  – ошибочно применена скидка 5%: 3999.99 × 0.95 = 3799.99, затем + 300 = 4099.99;  
  – неверная стоимость доставки: 3999.99 + 100 = 4099.99.  
  В любом случае требование нарушено: R2 не допускает скидку ниже 5000, R4 требует доставку 300 при сумме менее 4000.
- **Имя теста:** `RegularOrder_3999WithoutLoyalty_TotalIs4299`
